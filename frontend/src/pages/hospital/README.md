# Hospital Emergency Pages (`frontend/src/pages/hospital`)

## Purpose
Renders real-time hospital dispatch views, incoming emergency case monitors, active case lists, and capacity management forms.

## Key Pages
- **`HospitalEmergencyPages.tsx`:** Primary hospital emergency module handling both Emergency Cases broadcast stream and Active Cases queue.
- **`BedCapacityPage.tsx`:** Management interface for updating real-time bed counts.
