# Authentication Pages (`frontend/src/pages/auth`)

## Purpose
Renders user authentication views including login, user registration, OTP email/phone verification, and password recovery.

## Key Pages
- **`LoginPage.tsx`:** Universal login form supporting all user roles.
- **`RegisterPage.tsx`:** Patient and hospital account creation form.
- **`OtpVerificationPage.tsx`:** OTP entry screen for account credential updates.
