# Frontend Pages Directory (`frontend/src/pages`)

## Purpose
Contains complete page view components organized into portal sub-directories by target user role.

## Page Categories
- `admin/`: Administrator user blocklist and hospital verification pages.
- `auth/`: Login, registration, OTP verification, and password reset views.
- `doctor/`: Doctor assigned case review and patient history views.
- `hospital/`: Hospital Emergency Cases, Active Cases, and Bed Capacity management pages.
- `patient/`: Patient SOS Trigger, Doctor AI Assistant, HealthPack Document Vault, and Settings views.
- `public/`: Public landing page and hospital directory search.
