# Patient Portal Pages (`frontend/src/pages/patient`)

## Purpose
Renders patient-facing pages for emergency SOS triggering, Doctor AI triage assistance, HealthPack medical document vaults, and profile settings.

## Key Pages
- **`DoctorAIPage.tsx`:** Primary Doctor AI chat view featuring 5-part response cards, suggested question chips, and red-flag emergency banners.
- **`PatientEmergencyPage.tsx`:** One-touch SOS trigger view with live map and ambulance tracking.
- **`HealthPackPage.tsx`:** Document upload dropzone, file vault, and hospital consent manager.
- **`PatientSettingsPage.tsx`:** Profile management and OTP credential update forms.
