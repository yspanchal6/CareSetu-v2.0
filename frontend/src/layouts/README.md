# Portal Layouts (`frontend/src/layouts`)

## Purpose
Provides portal-specific layout wrapper components that embed Navbar, Sidebar, and role-appropriate navigation containers.

## Key Layouts
- **`PatientLayout.tsx`:** Layout for Patient portal pages (SOS, Doctor AI, HealthPack, Settings).
- **`HospitalLayout.tsx`:** Layout for Hospital portal pages (Emergency Cases, Active Cases, Capacity, Settings).
- **`AdminLayout.tsx`:** Layout for System Administrator management pages.
