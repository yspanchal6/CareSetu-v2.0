# Patient Components (`frontend/src/components/patient`)

## Purpose
Renders Doctor AI interactive chat assistant components, 5-part structured response cards, and emergency red-flag warning banners.

## Key Components
- **Chat Window:** Message container rendering user queries and structured Doctor AI assistant responses.
- **5-Part Response Card:** Card component displaying Understanding, Considerations, Recommended Next Step, Emergency Warning, and Follow-up sections.
- **Emergency Warning Banner:** Red alert banner triggered when active red flags are detected, featuring direct "Report Emergency Now" navigation button.
- **Suggested Question Chips:** Clickable query prompt chips for quick symptom triage testing.
