# Layout Components (`frontend/src/components/layout`)

## Purpose
Provides navigation headers, sidebars, page footers, and layout wrappers for all portal roles.

## Key Components
- **Navbar:** Top navigation bar displaying branding, user profile dropdown, and portal switcher.
- **Sidebar:** Left navigation menu with role-specific page links (Emergency Cases, Active Cases, Settings).
- **Footer:** Universal page footer with privacy links and copyright notices.
