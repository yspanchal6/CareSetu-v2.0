# Frontend Components Directory (`frontend/src/components`)

## Purpose
Contains reusable React UI components organized by domain area and user portal role.

## Sub-Component Folders
- `admin/`: Administrator dashboards, hospital approval cards, and user blocklist controls.
- `common/`: Reusable buttons, modals, input fields, badges, and loading spinners.
- `doctor/`: Patient record review panels, triage notes forms, and case overview cards.
- `emergency/`: One-touch SOS trigger button, live tracking map, and emergency contact list.
- `health-pack/`: Encrypted document upload dropzone, file list, and hospital consent toggles.
- `hospital/`: Active SOS alert popups, bed capacity management forms, and dispatch controls.
- `hospital-matching/`: Interactive Leaflet map displaying nearby matched hospitals and capacity indicators.
- `layout/`: Top navigation bars, sidebars, footer sections, and notification drawers.
- `patient/`: Doctor AI chat window, suggested question chips, and emergency red-flag warning banners.
