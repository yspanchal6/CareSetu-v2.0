# HealthPack Components (`frontend/src/components/health-pack`)

## Purpose
Manages patient medical record uploads, encrypted document listings, file pre-views, and hospital access consent grants.

## Key Components
- **Document Dropzone:** Drag-and-drop file upload zone enforcing PDF, JPG, PNG formats up to 10MB.
- **Medical File List:** Displays uploaded documents with file type badges and delete options.
- **Consent Grant Toggle:** Interface for granting time-bounded access to specific hospitals.
