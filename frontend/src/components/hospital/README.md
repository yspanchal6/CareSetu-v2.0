# Hospital Components (`frontend/src/components/hospital`)

## Purpose
Renders real-time hospital ER dispatch dashboards, active emergency queue popups, and bed availability managers.

## Key Components
- **Emergency Case Card:** Displays incoming SOS alert details, distance, ETA, and patient vital notes.
- **Bed Capacity Editor:** Form controls for updating General, ICU, Ventilator, and Oxygen bed counts in real time.
- **Accept/Reject Modal:** Modal for hospital dispatchers to accept or decline incoming ambulances.
