# CareSetu API Specifications Directory

## Folder Overview
This directory contains modular OpenAPI/Swagger specs, JSON schema definitions, and detailed API request/response samples for CareSetu backend services.

## Sub-Modules Documented
- **Auth API:** Authentication, registration, and OTP verification workflows.
- **Emergency API:** Geolocation SOS dispatch, real-time tracking, and hospital broadcasting.
- **Doctor AI API:** Chat message endpoints, RAG search query APIs, and document upload endpoints.
- **HealthPack API:** Patient medical record creation, document retrieval, and hospital consent grants.

Refer to master API documentation: [`../api.md`](../api.md).
