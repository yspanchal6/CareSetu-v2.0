# Backend Utilities Directory (`backend/src/utils`)

## Purpose
Provides reusable helper functions, formatting utilities, encryption wrappers, and math helpers.

## Key Utilities
- **`jwt.utils.js`:** Generates and verifies JSON Web Tokens.
- **`password.utils.js`:** Wraps bcrypt password hashing and comparison routines.
- **`geo.utils.js`:** Computes Haversine spatial distances between patient and hospital coordinates.
- **`logger.utils.js`:** Exports Winston application logger instance.
