# Backend Models Directory (`backend/src/models`)

## Purpose
Defines domain model interfaces, type aliases, and custom data structure definitions used across backend services.

## Key Models
- **`user.model.js`:** Represents authenticated User profiles, permissions, and status flags.
- **`emergency.model.js`:** Defines Emergency SOS payload structures, dispatch states, and hospital match results.
- **`chat.model.js`:** Defines Doctor AI message cards, NER entity structures, and RAG score containers.
