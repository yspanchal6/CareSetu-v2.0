# Prisma Database Schema & Migrations (`backend/prisma`)

## Purpose
Contains the central relational database schema definition (`schema.prisma`), migration histories, and custom client configuration.

## Key Files & Schemas
- **`schema.prisma`:** Defines database entity models (`User`, `EmergencyCase`, `Hospital`, `BedCapacity`, `MedicalDocument`, `HealthPackConsent`, `AIChatMessage`, `AIAnalysis`, `AccountCredentialUpdate`) and PostgreSQL PostGIS extensions.
- **`migrations/`:** Sequential SQL database migration scripts generated by `npx prisma migrate`.

## Useful Commands
```bash
# Push schema changes to database
npx prisma db push

# Generate updated Prisma Client
npx prisma generate

# Launch visual database GUI
npx prisma studio
```
